# 지자체 운영 공공 캠핑장 데이터

`camps` 테이블의 원천 데이터입니다. 조사일 2026-08-10.

## 파일

| 파일 | 건수 | 용도 |
|---|---|---|
| `camps_master.csv` | 329 | **시드 입력.** 위치·운영주체·시설 마스터 |
| `camps_reservation.csv` | 329 | **시드 입력.** 예약 정보 — 수기로 채우는 파일 |
| `참고_지자체운영_공립휴양림야영장.csv` | 127 | 지자체 운영 공립휴양림. `forests` 185건과 중복이라 미적재 |
| `참고_국가기관_민간_야영장.csv` | 129 | 국립공원공단·국립자연휴양림관리소·민간위탁 → 지자체 아님 |
| `참고_고캠핑후보_분류결과.csv` | 93 | 고캠핑 후보 전체와 운영주체 판정 근거 |

## 시드

```bash
npx tsx scripts/seed_camps.ts
```

`camps_master.csv` 를 읽어 좌표 없는 건만 카카오 지오코딩하고,
`camps_reservation.csv` 를 id 기준으로 병합해 `camps` 테이블에 upsert 합니다.
지오코딩 결과는 `scripts/camps_geocoded.json` 에 캐시되어 재실행 시 재사용됩니다.

## 예약 정보 채우는 법 ① 지도에서 직접 (권장) ★

`/map` 에서 캠핑장 마커를 클릭 → 하단 패널의 **✏️ 직접 입력** → 저장.
로그인이 필요하며(`/auth`), 저장하면 Supabase `camps` 에 바로 반영됩니다. 시드를 다시 돌릴 필요 없습니다.

- 자주 쓰는 값은 프리셋 칩을 눌러 한 번에 채울 수 있습니다.
- 필터 바에 `📅 예약 정보 n/329` 로 진척도가 표시됩니다.
- **⬇ CSV** 를 눌러 현재 내용을 `camps_reservation.csv` 형식으로 내려받아 이 폴더에 덮어쓰면 CSV와 동기화됩니다.
- 마이그레이션 `009_camps_reservation_edit.sql` 이 필요합니다.
  컬럼 단위 GRANT 라 로그인 사용자는 예약 관련 컬럼만 수정할 수 있고, 이름·좌표 등은 못 건드립니다.

## 예약 정보 채우는 법 ② CSV 일괄 편집

`camps_reservation.csv` 를 열어 아래 두 칸을 채우고 시드를 다시 돌리면 됩니다.

| 컬럼 | 예시 | 설명 |
|---|---|---|
| `reservation_open` | `이용월 1개월 전 1일 09시` / `매주 수요일 09시, 6주 전` | 예약 오픈 규칙 |
| `use_season` | `연중` / `3월~11월` / `4~10월 주말만` | 운영(이용) 기간 |
| `reservation_note` | `성수기 추첨제, 군민 우선예약` | 부가 설명 |

- 둘 중 하나라도 채워지면 `reservation_verified = true` 가 되어 지도 팝업과 상세 패널에 노출됩니다.
- 비어 있으면 "미확인 — 예약처 직접 확인"으로 표시됩니다.
- `reservation_org` / `reservation_url` 은 운영기관명과 공유누리 안내 페이지로 미리 채워 두었습니다(293건).

시드는 **CSV의 빈 칸으로 지도에서 입력한 값을 덮어쓰지 않습니다.**
(CSV에 값이 있으면 CSV가 이깁니다 — 일괄 수정은 CSV로 하세요.)

**초기 상태의 `reservation_open` / `use_season` 은 전건 비어 있습니다.** 원천 데이터(공유누리·고캠핑)에
예약 기간 필드가 아예 없고, 예약 오픈 규칙이 지자체마다 제각각이라 자동으로 채울 수 없었습니다.
(숲나들e를 쓰는 59곳조차 공립휴양림은 시설별로 정책이 달라 일괄 적용이 불가능합니다.)

## 출처

1. **공유누리 (eshare.go.kr, 행정안전부)** — 전국 국공립 야영장·휴양림 533건에서 지자체 운영분 추출.
   위경도·운영기관·전화·시설내역 포함 → `operator_verified = Y`, 294건.
   - `POST https://www.eshare.go.kr/UserPortal/Upd/UpdPubshrSvc/search.do`
     `{"eveCls":"EMS002","eveDetlCls":["001","002","003","004","005","006"], ...}`
2. **한국관광공사 전국 야영장 등록현황** (data.go.kr 15037499, 5,138건) — 공유누리 누락분 보강.
   `사업주체` 컬럼이 전건 공란이라 명칭 패턴으로 후보를 뽑고 운영주체를 수기 판정 → `operator_verified = N`, 35건.

## 알려진 한계

- 공유누리는 지자체 자발적 등록 체계라 누락이 있습니다.
  왕송호수 캠핑장(의왕), 강천섬 캠핑장(여주), 가야산오토캠핑장(성주) 등은 두 출처 모두에서 잡히지 않아 빠졌습니다.
- 공유누리는 시설 유형별로 행이 나뉘어 한 캠핑장이 2행으로 잡히는 경우가 있습니다(예: 망상오토캠핑리조트).
  좌표가 달라 지도상 별도 마커로 표시됩니다.
- 완전판을 원하면 공공데이터포털에서 고캠핑 API 키를 발급받아
  `https://apis.data.go.kr/B551011/GoCamping/basedList` 를 `facltDivNm=공공` 으로 수집하면 됩니다.
